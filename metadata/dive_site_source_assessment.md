# 潛點基本資料權威來源評估

評估日期：2026-09-18。此文件只評估來源，不下載、擷取或匯入任何潛點；`data/curated/dive_sites.csv` 保持空白。

## 結論

第一優先是交通部觀光署的[景點－觀光資訊資料庫](https://www.motc.gov.tw/201506260001/app/govdata_list/view?id=1615&module=&uid=201705110066)。該資料集提供空間化觀光資訊的 JSON/XML 資源、更新頻率為每日，並以政府資料開放授權條款釋出。它不是潛點專用資料集，因此不能整批視為潛點；只有同一筆開放資料同時明確寫出潛水／浮潛地點意義、名稱與座標時，才可送交人工逐筆審核。

在目前評估的五個來源中，沒有任何來源可直接自動匯入。即使第一優先來源也必須先保存原始資料 ID、URL、擷取日期、更新日期、名稱、WGS84 座標及活動定義，再由人工決定是否新增一筆 `dive_sites.csv`。這不是活動資格、合法性、現場條件或任何安全判定。

完整欄位化比較見 [dive_site_source_assessment.csv](dive_site_source_assessment.csv)。

## GoOcean 的特別判讀

GoOcean 首頁可視覺瀏覽「潛點」圖層，也提供活動、資料日期與相關資訊介面；這只證明圖台提供了可見圖層，不能證明每一個要素可被擷取、儲存或再發布。[服務條款](https://goocean.namr.gov.tw/ServiceTerms) 對國家海洋研究院本身具權利的網站資料提供了註明出處後的再利用條件，但同時排除另有聲明的素材與第三方權利；圖台的[資料與操作說明](https://goocean.namr.gov.tw/Information/index)也沒有公布潛點圖層的要素來源、坐標精度、版本或正式資料服務。

因此分三層處理：

- 可視覺瀏覽：可由人工在圖台查看，作為尋找原始主管機關來源的線索。
- 可合法擷取、儲存與再發布：目前**未確認**。不能以畫面、瀏覽器開發工具、未文件化端點、圖磚或批次爬取取代正式資料產品。
- 可作參考但不能寫入資料庫：在取得國家海洋研究院提供的圖層匯出／API、資料字典、來源機關、更新日、座標精度與再利用確認前，僅限人工參考與連結。

## 採用門檻

一筆資料只有同時滿足下列條件，才可能由人工複製到 `dive_sites.csv`：

1. 原始來源明確把該名稱描述為潛水地點、浮潛地點或潛點。
2. 同一原始紀錄可取得名稱與 WGS84 座標，且有穩定 URL 或資料 ID。
3. 授權可支援預定的產品公開呈現，並保留應有的顯名與版本資訊。
4. 人工覆核沒有以一般景點、活動分區、保護區、調查站、預報格點或座標接近關係替代直接佐證。

現有 eDNA、Reef Check、MPA、CWA 與《水域遊憩活動管理辦法》仍不具備上述條件；它們不會因本次來源研究而成為潛點資料。
