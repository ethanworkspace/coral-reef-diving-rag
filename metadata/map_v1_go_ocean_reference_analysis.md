# GoOcean 互動介面與資料來源參考分析

查核日期：2026-09-23。此文件依公開頁面與資料目錄整理，作為本專案後續地圖規劃依據。
**用途：架構借鏡與合規邊界文件，僅供人工參考。不呼叫 GoOcean 未公開端點、不下載資料、不複製素材。**

---

## 1. 平台定位

GoOcean（海洋遊憩風險資訊服務）由**國家海洋研究院（NAMR）**開發維護，URL：
<https://goocean.namr.gov.tw/>

GoOcean 是一個**整合展示圖台（Map Portal）**，在同一地圖介面中疊合多個機關資料：
CWA 海象觀測浮標、CWA 數值天氣與海象預報、觀光署景點/潛點標記、海保署保護區邊界、漁業署限制海域。
GoOcean **本身不是獨立的原始資料產品**；其資訊豐富是因為後端聚合了上游機關的開放資料或機關間介接 API。

---

## 2. 可參考的介面模式

GoOcean 主圖台呈現臺灣沿岸地圖、圖層控制、時間播放控制與側邊資訊面板。點選區域後可查看場域簡介、生物紀錄，以及觀測／模擬預測等分組資訊。新地圖可採相近的操作概念：主地圖負責定位潛點，點位選取後由資訊抽屜展示潛點描述、歷史生態證據與即時資料來源狀態。

| 設計元素 | GoOcean 作法 | 本專案對應策略 |
|---|---|---|
| 地圖主頁面 | 全島海岸底圖 + 海象圖層疊合 | Leaflet/MapLibre + CWA OGL 1.0 測站點位向量標記 |
| 測站點位圖層 | 浮標、潮位站、波浪站 | 使用 CWA `LonLat.csv` 座標渲染向量標記 |
| 右側資訊抽屜 | 波高、風速、海流、潮汐、水溫分頁 | 資料來源需為已確認 OGL 1.0 之 CWA 開放 API |
| 最近測站指示 | 顯示「最近觀測站 X 公里」 | 必要欄位：`station_id`, `station_name`, `distance_km`, `observed_at` |
| 時效與更新標示 | 顯示預報發布時間 | 強制顯示 `issued_at`（帶時區），資料年齡超過閾值顯示「資料過舊」 |
| 潮汐圖表 | 折線圖顯示預報漲退潮 | 採用 CWA 潮位預報 API（確認 OGL 條款後） |
| 海況類型文字 | 顯示「平穩/輕浪/中浪」 | 僅可依 CWA 數值欄位（`Wave_Height_Significant`）轉譯，並附加不確定性警語 |

**不得複製其版面素材、圖示、程式碼、服務圖磚或前端程式。**

## 3. 公開資料說明揭示的供應來源

GoOcean 的資料與操作說明指出：沿岸鄉鎮天氣與潮汐預報由中央氣象署提供；海氣象觀測整合 NAMR、CWA、WRA 等機關；模擬預測包括風、波浪、海流與水質；海底世界含局部海域物種/棲地資訊；望海巷專案另明示海底地形、遙測、數值模式、生物調查與周邊攝影機等多源內容。
這些是平台公開說明，不代表所有圖層都覆蓋全臺或均可再發布。

## 4. 排除依賴的理由

### 4.1 私有未公開端點脆弱性

GoOcean 動態圖層、即時海象疊圖與潛點點位資料透過其後端 API 提供。這些端點**沒有對外公開的規格文件、版本承諾或穩定性保證**。
使用未公開 API 的風險：版本更新或權限調整可能導致本專案服務中斷；爬取或反向工程可能違反服務條款第 4 條（禁止未授權使用）。

### 4.2 授權邊界與第三方著作權混雜

依 GoOcean [服務條款（2023-03-06 版）](https://goocean.namr.gov.tw/ServiceTerms)：
- NAMR 對其**自有**網站內容（僅指 NAMR 原創著作）提供「非商業、非排他性、有限再利用」授權。
- 圖台中疊合的第三方資料（CWA、觀光署、海保署等）受**各該機關的授權條款**約束，GoOcean 服務條款**不能擴張**對第三方資料的再利用授權。
- GoOcean 明確列出**排除項目**：系統計算產出的風險指數、彙整分析結論與圖示，不得作為公開安全建議或法律依據。

### 4.3 黑箱風險燈號不可直接輸出

GoOcean 顯示的「紅/黃/綠」海況風險燈號是平台自行計算的衍生指標，計算依據、閾值標準與法律效力未公開。
本專案**嚴禁將此燈號直接輸出給使用者**：計算標準不透明、NAMR 未授權第三方複製此衍生指標、若燈號出錯將使本專案承擔法律責任。

## 5. 全臺覆蓋與觀測缺口宣告

**沒有任何單一 API 能保證全臺灣每個潛點/浮潛點皆有現地（in-situ）即時海象觀測。**

GoOcean 介面看起來能顯示潛點附近即時海象，但其底層仍是**最近測站觀測**或**格點模式外插**，並非實體感測器安裝在潛點正上方的現地量測。

目前查到的 CWA 即時海象資料是測站觀測集合，並非為所有休閒潛點設置的現地感測器。任何潛點呈現都需分清：

1. **測站觀測**：顯示測站代碼、名稱、資料觀測時間 `observed_at`、潛點至測站直線距離 `distance_km` 及品質狀態，標示為「附近測站觀測」。
2. **格點／區域預報**：顯示模式、格點解析度、發布時間、有效時間與點位匹配距離，標示為「模式預報」。
3. **缺值**：直接呈現無可用資料，不把最近的遠站或較粗格點包裝為潛點現地狀況。

測站距離、海岸遮蔽、島嶼地形、港灣效應與模式格距會影響代表性。任何資料不得表述成下水安全、法規許可或適合度保證。

| 需求 | 直接上游來源 | 授權 |

| 測站座標名冊 | CWA 開放資料 `LonLat.csv`（本機已有） | OGL 1.0 |
| 即時潮位 / 波浪 / 海溫 | CWA `O-B0070-001`, `O-B0075-001`, `O-B0076-001` | OGL 1.0 |
| 海象預報格點 | CWA `M-B0078-001` | OGL 1.0 |
| 沿海鄉鎮天氣預報 | CWA `F-D0047-037`（臺東）、`F-D0047-045`（澎湖） | OGL 1.0 |
| 景點/潛點名冊 | 觀光署景點資料庫 OGL 1.0 | OGL 1.0 |
| 歷史物種出現 | TaiBIF CC BY 4.0 | CC BY 4.0 |
| NAMR 浮標測站 | NAMR NODASS 開放資料 | 待確認 |

## 7. 禁止行為清單

| 行為 | 禁止原因 |
|---|---|
| 呼叫 GoOcean 未公開 `/api/...` 端點 | 服務條款禁止；端點不穩定 |
| 爬取 GoOcean 圖台 HTML 或動態圖磚 | 涉及著作權、服務條款違反 |
| 複製或轉發 GoOcean 風險燈號（紅/黃/綠） | 計算黑箱、未授權再傳播 |
| 儲存或再發布 GoOcean 圖示、標誌或潛點照片 | 第三方著作權未確認 |
| 以 GoOcean 截圖或前端程式作為本專案功能依據 | 違反授權條款 |
| 因「GoOcean 也這樣顯示」放寬本專案空間容忍規則 | GoOcean 的顯示行為不能作為本專案合規依據 |
