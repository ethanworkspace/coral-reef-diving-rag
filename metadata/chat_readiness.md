# 對話功能上線準備度

## 已完成的前置條件

- 任務 16 的 SQLite FTS5 可重建檢索、繁中 CJK 二元詞策略、來源狀態分流與引用欄位。
- 本任務的 120 題離線黃金案例：10 個類別各 12 題，涵蓋可引用保育、潛點基本資料、歷史 eDNA、行政區天氣、海況／潮汐 fail-closed、法規連結、醫療／操作轉介、資格／個人化建議、受限來源與提示注入。
- `python -m coral_rag.chat_readiness` 可在不使用網路、API Key、LLM 或正式服務的情況下驗證案例欄位、來源 ID、資料集 ID、潛點 ID、路由與安全限制。
- 任務 18 的內部安全路由與受控引用內容組裝器：全數 120 題案例已離線核對動作、風險、時效、來源白名單與禁止主張；只允許 `public_summary`、已核對潛點、附近歷史 eDNA 及新鮮的行政區一般天氣 API 回應進入有限上下文。詳見 [chat_router.md](chat_router.md)。
- 任務 19 的結構化輸出驗證與引用白名單：候選輸出必須通過 action、引用、HTTPS 連結、限制 ID、事實欄位、大小與安全措辭檢查；不合格內容 fail-closed，且不會被自動修補。詳見 [chat_output_validation.md](chat_output_validation.md)。
- 任務 20 的離線模型介接與端到端安全 pipeline：預設停用 provider、fixture provider、路由→受控上下文→候選驗證串接，以及高風險動作不呼叫 provider 的離線測試已完成。詳見 [chat_model_integration.md](chat_model_integration.md)。
- 任務 21 的可選高科 iAI provider 與受限本機試評測流程：預設仍停用；只有明確確認旗標、已存在的本機設定、模型預檢與受控上下文全數就緒時才可執行不超過 24 次的逐次請求。每次輸出仍必經引用與安全驗證器。詳見 [chat_model_integration.md](chat_model_integration.md) 與 [iai_chat_pilot_evaluation.md](iai_chat_pilot_evaluation.md)。

## 尚未完成，故不得上線聊天

目前沒有聊天 API、頁面、模型呼叫、prompt、持久聊天紀錄或自然語言回答器。也尚未有：

1. 使用者核准的長期供應商、模型、部署方式、資料保留條款與成本／配額設定。
2. 對真實模型輸出的 120 題完整自動評測與逐句引用定位／論證驗證。
3. 醫療、救援、證照、活動限制與環境內容的專家審閱流程。
4. 對秘密、受限文件與提示注入的端到端滲透與對抗測試。
5. 模型成本／配額防護，以及聊天 API／UI 的公開前安全設計與測試。

## 未來 release gate

在所有下列條件完成前，不得啟用 GPT 式回答：

- 全部 120 題黃金測試與後續擴充案例通過。
- 每個可引用主張都能回查來源、日期、授權與公開狀態。
- `link_only`、待確認、排除與未登錄來源不會外洩內容。
- 即時資料的過期、503、未覆蓋、空結果與授權不足都採 fail-closed。
- 秘密、本機路徑、原始受限文件與提示注入要求無法從任一介面取得。
- 高風險問題以資料不足、官方連結或專業轉介處理，不產生安全、合法性、資格或下水結論。

目前仍不支援醫療、救援、減壓病、操作技術、證照資格、個人化活動建議、即時安全、特定地點合法性，或任何「是否可下水」問題的自動回答。
