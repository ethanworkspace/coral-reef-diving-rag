# 屏東沿海官方潛點候選核驗報告 (Map V1 Pingtung Tourism Source Review Report)

## 1. 任務背景與目標

本報告針對交通部觀光署《景點－觀光資訊資料庫》（政府資料開放平台 dataset/7777）中屏東縣沿海地區（以墾丁及小琉球為優先核驗區，並全面掃描東港、林邊、車城、枋寮等沿海鄉鎮）之景點資料進行唯讀審核。

目標在於嚴格核對官方資料之原始欄位、空間坐標系統（CRS）、活動定義與實體屬性，判斷是否有任何景點符合 [潛點資料契約](file:///C:/my%20project/coral-reef-diving-rag/metadata/dive_sites_data_contract.md) 之潛點候選標準，可安全納入下一階段評估。

**重要執行原則**：
- 本任務維持唯讀審核，**絕不修改** 正式潛點名錄 `data/curated/dive_sites.csv`、資料庫、API 或前端地圖。
- 嚴格遵守「潛水／浮潛文字僅作為進入人工審核之線索，絕不把附近有潛點、港口碼頭、活動列表或整體區域介紹轉化為該點坐標潛點」之防護原則。
- 若無紀錄同時具備明確潛點定義、可追溯坐標與清楚 CRS，如實判定 **0 筆通過**，不放寬標準硬湊候選。

## 4. 關鍵案例深度剖析與排除理由

### 4.1 白沙觀光港 (`Attraction_A15010400H_000433`)：港口碼頭航安疑慮與鄰近文字借用

- **原始名稱**：白沙觀光港
- **坐標**：緯度 22.35312，經度 120.3831（WGS84）
- **官方原始描述摘錄**：
  > 「白沙觀光港為遊客進出之主要港口，緊鄰海岸線優美的中澳沙灘，深具遊憩價值，港區內之遊客服務中心，除了提供交通船的搭乘外，尚有海上環島船以及海底半淺艇...鄰近的中澳沙灘因海流十分穩定，非常適合戲水、弄潮以及浮潛活動...」
- **審核判定**：`excluded`
- **排除原因代碼**：`harbor_terminal_referencing_neighboring_beach`
- **架構與領域安全理由**：
  1. **實體為渡輪港口碼頭**：該坐標為小琉球東港往返交通船、公營船與民營船隻頻繁靠泊起錨之商港與客運航道。
  2. **內文浮潛為鄰近景點引述**：描述中提到「浮潛」活動明確指涉「鄰近的中澳沙灘」，並非白沙觀光港水域本身。
  3. **航行與人員生命安全防護**：若因抽取到「浮潛」字眼，逕行將白沙觀光港標註為可潛水的潛點，使用者若依 App 導引至該港區下水，將與大型客輪航線重疊，存在致命之海上航安風險。因此依資料契約第一條與防護規約，堅決排除。

### 4.2 小琉球天然沿海景點：官方描述缺乏直接潛水／浮潛定義

包含小琉球 6 處知名沿海景點：
1. **花瓶岩** (`Attraction_A15010400H_000461`)：描述重點為靈山寺前地標、地殼隆起之珊瑚礁海蝕奇岩、頭大身小造型與退潮近照生態之旅。未提及「潛水」或「浮潛」。
2. **美人洞** (`Attraction_A15010400H_000432`)：描述重點為珊瑚礁石灰岩洞穴步道、蝙蝠洞、仙人洞等奇石與高處眺望大海。未提及「潛水」或「浮潛」。
3. **厚石裙礁** (`Attraction_A15010400H_000475`)：描述重點為紅番石、觀音石、爬山虎石等奇岩怪石造型與昔日晒鹽凹洞。未提及「潛水」或「浮潛」。
4. **中澳沙灘** (`Attraction_A15010400H_000490`)：該景點自身的官方描述為「最適合海泳、戲水、海釣以及其他的海濱遊憩活動...迎王請水儀式」，雖然在白沙港描述中被提及適合浮潛，但中澳沙灘自己的資料項目未列潛水或浮潛，官方分類亦非潛點。
5. **蛤板灣沙灘** (`Attraction_A15010400H_000469`)：描述重點為威尼斯沙灘之稱、白沙弧線、貝殼砂與夜間漫步聽濤。未提及「潛水」或「浮潛」。
6. **多仔坪潮間帶** (`Attraction_A15010400H_000451`)：描述重點為夜間潮間帶生態導覽（光掌硬殼寄居蟹、招潮蟹、海星等）。未提及「潛水」或「浮潛」。

- **審核判定**：全數 `excluded`
- **排除原因代碼**：`coastal_natural_site_lacks_direct_dive_definition`
- **理由**：潛點名錄契約強調「來源權威性與活動定義法定性」，資料集提供機關（觀光署大鵬灣管處）在景點建檔時將其定義為奇岩觀賞、步道健行、沙灘漫步或潮間帶觀察。系統不允許憑開發人員個人經驗或外界常識越俎代庖補充活動屬性。

### 4.3 大潭濕地與鵬村濕地：污水淨化工程「潛流」非休閒潛水

- **大潭濕地** (`Attraction_A15010400H_000482`)：內文出現「潛流式過濾池（過濾介質為廢磚塊、混凝土塊及礫石、牡蠣殼）」，為暴雨逕流與養殖廢水沈澱過濾工程。
- **鵬村濕地** (`Attraction_A15010400H_000483`)：內文出現「增設潛流式濕地系統，幫助去除水中大部分的污染物」，為人工濕地水質淨化設施。
- **審核判定**：`excluded` (`constructed_wetland_water_treatment_facility`)。

## 5. 體制性資料缺口揭露 (Institutional Source Gap Analysis)

### 5.1 墾丁國家公園海域景點完全缺漏

在對整份 6,195 筆觀光署快照進行全量檢索時，我們發現全臺灣最著名的潛水勝地——**墾丁海域潛點**（後壁湖、萬里桐、船帆石、南灣、小灣、合界、紅柴坑、出水口、貓鼻頭等）在資料庫中 **完全沒有獨立紀錄**（命中數為 0 筆）。

### 5.2 體制成因分析

1. **主管機關權責分立**：
   - 觀光署（`A15010000H`）隸屬交通部，其所轄國家風景區包含大鵬灣與小琉球（大鵬灣國家風景區管理處 `A15010400H`）。因此小琉球與東港地區景點相對完整。
   - 墾丁地區屬於「墾丁國家公園」，管轄機關為 **內政部國家公園署**（前內政部營建署國家公園組）墾丁國家公園管理處。
   - 交通部觀光署之《景點－觀光資訊資料庫》母體中，並未收錄國家公園署細緻之水下或海域遊憩專區景點。
2. **治理建議與下一階段方向**：
   - 若要建立合規、具備坐標與活動規範之墾丁官方潛點名錄，**不應繼續在觀光署景點資料庫中檢索**。
   - 應轉向 **內政部國家公園署（墾丁國家公園管理處）** 發布之水域遊憩活動管制公告、海域分區規劃或專屬開放資料集（如「墾丁國家公園海域遊憩活動分區及管理規定」），才能取得法定、合規且具代表性之墾丁潛點候選。
