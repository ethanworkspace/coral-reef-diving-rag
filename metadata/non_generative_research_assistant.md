# 本機非生成式研究問答

頁面 `/assistant` 是本機研究證據入口，不是 GPT、LLM 聊天或自動回答服務。它不呼叫 iAI、chat pipeline 或輸出驗證器，也不儲存問題、結果、帳號資料、聊天紀錄、analytics 或 telemetry。

使用者輸入問題，必要時主動選擇已驗證潛點、eDNA 半徑或未來天氣時間範圍。後端只呼叫既有 `chat_router`，並依其既有動作組裝受控結構化資料：公開保育來源 FTS、潛點代表點、附近歷史 eDNA 或具新鮮度的行政區一般天氣。eDNA 與天氣在缺少必要條件時不查詢；天氣資料過期、缺少或未覆蓋時維持資料不足。

`link_only` 只提供核准官方連結；`data_insufficient` 不推測；`redirect_professional` 轉介醫療、救援、操作、證照與個人化建議；`refuse` 不回顯秘密、本機檔案或提示注入內容；`needs_clarification` 要求選擇潛點、半徑或具時區範圍。所有外部連結只允許 HTTPS，前端以文字節點呈現資料。

本頁不顯示潮位、波流、受限 Reef Check 或受限來源原文；不把 eDNA 表示為可見魚類，不把行政區天氣表示為海況、現場天氣、下水建議或安全結論。未來即使 iAI 修正，模型也只能在既有安全路由、受控上下文與引用驗證器通過後接入，不能改變這些資料限制。
