## 1. 執行背景與查證原則

澎湖縣政府網站掛載之未署名 PDF 文件（文號檔名：`3270308_0023451_114E1003167-01.pdf`，SHA-256: `96be8d4676a3342c53d1d62978362778608a956920c3999ee6c91e2e004294ef`）雖收錄全臺 273 筆潛點名稱與座標，但經任務 7 溯源審查發現：該檔無標題、無編製機關、無座標系統說明（CRS）、無授權宣告，且混入 7 處陸域室內深水池／游泳池。

本階段依據指令，**不寄送詢問函，不安排任何公文與機關聯繫**，全面轉向「**公開官方來源獨立查證**」：
1. **點位線索隔離**：僅以 PDF 潛點表中的名稱與區域作為檢索線索，**PDF 本身記載之經緯度座標絕不作為任何核驗佐證依據**。
2. **官方佐證門檻**：必須由公開發布之中央主管機關、地方政府法規公告或政府資料開放平台資料集，同時具備「官方明確潛點／水域遊憩定義、法定代表座標、明確 CRS（如 WGS84）、明確開放再利用授權（如 OGL 1.0）」。
3. **未符門檻一律待審**：任一要件未齊備者，決策一律維持待審（`pending_review`），**嚴禁標記為核准，嚴禁匯入正式潛點庫**。
4. **正式庫零異動保護**：正式潛點庫 `data/curated/dive_sites.csv` 維持既有 5 筆，SHA-256 雜湊嚴格維持 `68a1bfae66ccd443aa2cf38c08cec106654ff0c30f03d072c29442e58068c770`。

## 4. 關鍵技術與治理分析

經由本次跨區代表點的獨立官方來源比對，可歸納出全臺潛點資料治理之三項關鍵瓶頸：

1. **法規管轄分區（Polygons）與休閒活動點位（POIs）的脫鉤**：
   - 國家公園管處（如墾管處、海管處）及各縣市政府主管機關，其法規公告均以多邊形（Polygons）或沿岸距離（如距岸200公尺）進行空間劃界，職責在於「管制範圍」，而非提供「休閒遊憩下水點（Access Points）」。
2. **觀光資訊庫陸域入口與水域活動點的空間漂移**：
   - 觀光署 POI 資料集主要服務陸域遊客與導航，其座標多落在停車場、景點解說牌或步道入口（如潮境公園點位落在草坪，與水邊相差 108 公尺）。此類陸域點位不能直接等同水下潛點。
3. **PDF 座標拼湊本質與精準度偏差**：
   - 石朗案例最具代表性：即便官方有明確的石朗潛水區開放點位，PDF 記載之座標仍與官方點位產生高達 90 公尺之偏差。這證明整份 PDF 係民間多源資料之非標準化彙編，絕不可作為地圖模組的直接圖資來源。
