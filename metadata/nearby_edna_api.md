# 潛點附近歷史 eDNA 證據 API

## 路徑與參數

```text
GET /api/dive-sites/{site_id}/nearby-edna?radius_m={radius_m}&limit={limit}&offset={offset}
```

| 參數 | 必填 | 範圍 | 說明 |
| --- | --- | --- | --- |
| `site_id` | 是 | 已存在的潛點 ID | 查詢該潛點的官方景點代表點。不存在時回傳 HTTP 404。 |
| `radius_m` | 是 | 整數 `1`–`5000` | 以公尺表示的即時計算半徑。缺少或超出範圍時回傳 HTTP 422。 |
| `limit` | 否 | 整數 `1`–`100`，預設 `50` | 單頁最多回傳 100 筆。 |
| `offset` | 否 | 整數 `0`–`10000`，預設 `0` | 依距離排序後的分頁位移。 |

5 公里上限使結果維持為局部、可檢視的歷史採樣證據，並降低將跨區域資料誤當成潛點生物資料的風險。單頁 100 筆上限避免一次輸出大量分類群紀錄；完整命中數與是否仍有下一頁由 `pagination` 提供。

## 距離計算與查詢方式

API 先以緯經度包圍盒縮小查詢範圍，再以 Haversine 大圓距離作精確篩選。計算使用 WGS84 經緯度與 IUGG 平均地球半徑 `6,371,008.8 m`；只有未四捨五入的距離小於等於 `radius_m` 才會納入，回應的 `distance_m` 四捨五入至整公尺。

關聯完全在請求期間計算。系統不建立潛點與 eDNA 的關聯表、不寫入查詢結果，也不快取衍生結論。現有 `(latitude, longitude, sampled_at)` 索引只用於安全的候選前篩選。

## 回應重點

- `evidence_type`：固定為 `nearby_historical_edna_evidence`。
- `dive_site`：潛點 ID、原始名稱、官方代表點、來源與最後核對日期。
- `query`：實際半徑、距離方法、地球半徑與允許的最大半徑。
- `pagination`：`offset`、`limit`、本頁筆數、完整命中數與下一頁位置。
- `items[].distance_m`：潛點代表點到歷史採樣座標的衍生距離。
- `items[].source_record_id`：`來源檔名#data-row=列號`。列號從 1 開始，CSV 時不含標題列。
- `items[].station_id`、`sampled_at`、`sample_position`、`depth_m`：來源中的站點、日期、座標與深度。
- `items[].taxon`：來源中的學名、中文學名、科名與中文科名；每一列只表示可回查的單筆歷史 DNA 偵測紀錄，不可彙總成潛點生物狀態。
- `items[].source`：海洋保育署資料集網址、來源檔與列號、OGL 1.0 名稱、網址及顯名文字。
- `items[].data_quality`：座標、日期與識別碼限制。
- `limitations`：每次回應均附上的固定限制文字。

## 識別碼與資料限制

原始資料沒有獨立、全域唯一的樣本 ID。專案以特定下載版本中的 `source_file + source_row` 作為可重現的原始紀錄定位方式；站點名稱另存為 `station_id`，但同一站名可能跨日期、檔案或座標出現，不能單獨視為樣本 ID。

目前 19,736 筆匯入紀錄都有站點、座標、採樣日期及至少一個分類群名稱，日期範圍為 2021-01-11 至 2024-06-14。日期只有日級精度。來源沒有逐筆提供座標不確定度；即使座標有多位小數，`distance_m` 也只是由代表點與歷史採樣座標計算的衍生值，不代表實際定位精度。

## 固定限制與授權

1. eDNA 是歷史採樣位置的 DNA 偵測，不是現場目擊或當日生物狀態。
2. 潛點座標是官方景點的代表點，不是入口、活動範圍或採樣位置。
3. 距離接近不等於生物存在於該潛點，也不表示可見性、合法性或下水安全。
4. 使用結果時必須保留「海洋保育署『臺灣周邊海域環境 DNA 採樣調查資料』」來源，並依[政府資料開放授權條款第 1 版](https://data.gov.tw/license)標示。

本 API 只查詢 `edna_occurrence`，不查詢或輸出 Reef Check 資料。
