# 澎湖縣府網站掛載疑似全臺潛點座標表溯源與核驗報告 (Map V1 Penghu Hosted Dive Table Provenance Report)

## 1. 任務背景與查核目標

在任務 6 確立墾丁國家公園管理處水域管理分區缺乏經緯度數值與空間坐標系統（CRS）後，搜尋索引中浮現一筆掛載於澎湖縣政府網站之 PDF 檔案。該檔案內含全臺多縣市之「潛點名稱、經緯度、區域、縣市」資料。

本任務旨在對該份 PDF 進行嚴謹的**文件溯源（Provenance）**、**發布背景與機關權責審查**、**法定再利用授權核驗**、以及**坐標定義與空間參考系統（CRS）核驗**。

**核心執行原則**：
- **搜尋摘要與快取不可作為來源證據**：先前列為失效之交通部航港局舊網頁目前開啟確為 HTTP 404（Not Found），搜尋引擎之快取摘要或標題片段不得作為官方資料來源佐證。
- **經緯度數值落在臺灣不等於 WGS84**：官方文件若未明確說明 CRS、基準橢球體（Datum）與軸序，不得擅自推定為可供地圖建置之合規空間數據。
- **嚴防偽官方潛點與室內設施混淆**：資料若混入室內游泳池、商業深水池或港口航道，必須嚴格標記排除。
- **四項要素缺一即維持待審**：發布機關、計畫脈絡、開放授權、CRS 證據任一項未獲法律確認，整份資料一律標記為 **`pending_review`**（待審），**絕不匯入正式潛點庫**。

## 6. 空間參考系統 (CRS) 與坐標資料性質分析

### 6.1 坐標標題與格式特徵

- 表格坐標欄標題為英文與中文並列：`經緯度 (latitude & longitude)`。
- 全文 10 頁共 273 筆紀錄，所有坐標均採 `緯度,經度`（以逗號分隔）之十進位表示法。
- **完全無 CRS 註記**：全篇未提及 WGS84、TWD97、TWD67 或任何 EPSG 空間代碼。

### 6.2 坐標精度異質性揭露（多源混雜證據）

經對全量 273 筆坐標進行數值精度分析，呈現明顯之多源混雜特徵：
1. **單精度浮點數（IEEE 754 float32）截斷特徵**：
   - 例如序號 1 杉福漁港 `22.339233398438, 120.36222076416`、序號 70 鎮海艦 `22.3219795227051, 120.355926513672`、序號 150 鼻頭角 `25.1226272583007, 121.909523010253`。
   - 小數點後帶有二進位轉十進位之長尾冗餘位數，顯為手機 App 或早期資料庫以 float32 儲存時之特徵。
2. **度分秒（DMS）轉十進位之循環小數特徵**：
   - 例如序號 85 七星岩 `21.7591666666667, 120.814666666667`（即 $21^\circ 45' 33''$, $120^\circ 48' 53''$）。
3. **概略性截斷坐標**：
   - 例如序號 7 後壁湖出水口 `21.9312, 120.745`、序號 123 龍洞海洋公園 `25.119, 121.919`，僅保留 3~4 位小數（定位誤差達百米以上）。
4. **點位物理意義混淆（重大領域缺陷）**：
   - 經緯度有的是**陸域室內建築**（如運動中心大門）、有的是**港口碼頭泊位**、有的是**水下沉船**、有的是**沿岸沙灘**。表格並無點位定義說明（是出入水點？水下礁體？還是停車場？）。

**空間核驗結論**：
- 僅憑欄位名稱「經緯度」或坐標數值落在臺灣周邊海域，**不足以單獨證明其空間基準為 WGS84**，更無法證明其坐標精度滿足導航與潛水安全要求。
- 判定狀態：**`unconfirmed_crs_pending_review`**。
