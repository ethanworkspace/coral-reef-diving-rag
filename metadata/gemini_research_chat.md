# 本機 Gemini 受控研究問答

此模式只在本機研究服務中使用，預設維持非生成式研究問答。使用者必須明確勾選「使用 Gemini 研究問答」，而且本機未提交設定的 Gemini provider 必須已通過固定 JSON 協定探測，系統才可能送出模型請求。

每次模型請求都固定走：安全路由 → 受控來源內容 → Gemini provider → 引用與安全驗證器。只有 `public_summary` 保育來源、來源核對的潛點基本資料、附近歷史 eDNA 與通過新鮮度檢查的行政區一般天氣可進入受控內容；受限來源、Reef Check、潮位、海況、個別合法性、安全、醫療、救援、操作、證照、推薦與提示注入在模型前即會被阻斷。

服務程序最多允許 20 次 Gemini 請求；每題上限為 800 字元。系統不儲存問題、候選輸出、回答、對話紀錄或 telemetry。模型輸出只有在既有驗證器確認 action、引用、HTTPS 連結、限制文字與結構化事實都符合本次受控內容時才會呈現；否則只顯示「本次回答未通過研究驗證」等安全狀態。

Gemini 的 API key、base 設定與模型名稱只可存在本機未提交設定，絕不可寫入版本控制、測試輸出、畫面、紀錄或錯誤訊息。協定探測成功僅表示最小 JSON 對話格式可用，不代表研究回答品質、安全性、引用完整性或公開上線資格。Gemini 的 JSON 結構化輸出仍需由本專案驗證器做 fail-closed 驗證；相關官方能力說明見 [Gemini Structured Outputs](https://ai.google.dev/gemini-api/docs/structured-output)。
