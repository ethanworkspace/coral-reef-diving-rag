# 可公開海況與天氣來源評估（任務 10）

查核日期：2026-09-19。這是來源與覆蓋可行性評估，不新增下載、SQLite 資料、API、前端、排程或任何活動／安全判定。

## 範圍與既有資料限制

- 評估對象是目前五筆 `source_verified` 景點代表點：四筆在臺東縣綠島鄉（石朗潛水區、綠島南寮漁港、柴口浮潛區、大白沙），一筆在澎湖縣白沙鄉（險礁嶼）。這些是觀光署景點的 WGS84 代表點，不是入口、活動範圍、量測站或安全位置。
- 既有 `M-B0078-001` CWA 波流產品在本專案已有 4,080 筆快照；它有 OGL 1.0 的政府資料開放平臺登錄，但既有 API 的空間規則正確拒絕了五點，不能因需要顯示資料而放寬。
- `F-A0021-001` 潮位資料只在已授權的本機研究範圍完成結構化。其公開 API、網頁展示與再發布權利尚未確認；依本任務限制，**不列為公開候選**，也不作為任何缺口的補值。
- 所有候選都是預報或區域資料；沒有任何資料可被描述為潛點現場量測、潛點活動建議、合法性、安全性或適合度。

## 評估方法與門檻

`marine_weather_source_assessment.csv` 有 20 列：4 個候選產品 × 5 個既有代表點。每列同時保留產品欄位、時間、權利、來源 URL，以及「最近站點／格點／區域」和判斷。空白 `distance_m` 表示來源是行政區／海域區域產品，或本次沒有可公開、可回查的位置座標；不是距離為零。

對「海況」採較嚴格門檻：需要明確公開再利用權利、明確產品位置／區域對應、具時區的發布時間與有效時間，以及能解釋的空間代表性。對「一般天氣」可接受行政區同名的覆蓋關係，但顯示名稱必須是「綠島鄉一般天氣預報」或「白沙鄉一般天氣預報」，不可降格稱為某潛點的天氣或海況。

## 最小可行公開資料組合（僅建議，不實作）

1. **一般天氣：可先採用。** 使用 OGL 1.0 的 CWA F-D0047-037（綠島鄉）與 F-D0047-045（白沙鄉），每筆資料固定顯示行政區、發布時間、有效時間、來源「交通部中央氣象署」、資料集名稱及 OGL 1.0。建議只在 `IssueTime` 可解析、具時區且資料年齡不超過 **8 小時** 時顯示；8 小時是對官方每 6 小時更新頻率預留 2 小時取得／處理緩衝的工程新鮮度門檻，不是預報品質保證。
2. **海況：保持留白。** M-B0078-001 對現有五點沒有通過空間條件；F-D0047-095 和 F-A0012-001 尚缺可公開使用與位置對應證據。因此第一版公開產品不得顯示波高、波向、週期、流速、流向或「海況」結論。
3. **潮位：保持留白。** 本機研究用的結構化潮位資料不是公開資料候選，不能以有下載檔或有測站名稱推定展示／再發布權利。
4. **一律保留限制。** 所有預報都不是現地量測；行政區／海域區域與景點代表點可能有空間差異；資料不單獨用於合法性、安全性或是否適合下水的判定。保留來源與授權標示不等於 CWA 對產品應用背書。

## M-B0078-001 為何不覆蓋目前五點

這不是單一因素：

- **不是廣域資料缺失。** 五個點都在既有快照發布位置的外框內，而且資料集本身已成功解析；因此不能說整個產品不涵蓋綠島或澎湖。
- **是產品發布位置與代表點的距離過大。** 最短仍為 1,792.8 m，最遠 2,662.5 m。既有規則要求「在發布位置外框內，且距離不超過 `min(1,000 m, 最近不同發布位置距離的一半)`」，五點全數失敗。
- **保守規則不是任意障礙。** 原始快照未明示原生模式格距、完整有效海域／陸海遮罩或座標基準。已發布位置的相鄰距離也不等於原生格距；在缺乏這些資訊時，不能以 1.8–2.7 km 的距離推定近岸代表性，尤其不能跨越地形或海岸線解釋。
- **需要不同證據，而非放寬門檻。** 可驗證的下一步是：向 CWA 取得 M-B0078-001 的 CRS、模式格網、有效海域與位置代表性文件；或取得 F-D0047-095 的正式位置清單、區域對應與公開再利用條款。取得前，保持空結果是正確行為。

## 驗證方式

- 讀取 `data/curated/dive_sites.csv`，確認五筆 ID、名稱、WGS84 坐標、縣市與行政區；未新增或修改任何列。
- 對照 [Task 8 的波流 API 文件](marine_forecast_api.md) 中、由既有原始快照得出的五筆最近位置與 Haversine 距離；沒有重新下載、修改快照或調整空間規則。
- 逐一查核官方 CWA 產品目錄／說明與政府資料開放平臺頁面。僅當政府資料開放平臺對特定產品明示 OGL 1.0 時，才標為可公開候選；未確認者保守列為暫緩。
- 此任務只新增本 CSV 與本說明文件；未改動 SQLite、CSV 潛點、API、前端、設定或測試，也未停止服務。
